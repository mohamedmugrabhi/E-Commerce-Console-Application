# E-Commerce Console Application

A console-based e-commerce application built with C#, Entity Framework Core, and SQL Server. The project demonstrates database integration and object-oriented application development.

## Features

- Manage products and categories.
- Work with customer and order-related entities.
- Perform database operations using Entity Framework Core.
- Use asynchronous database operations where implemented.
- Configure SQL Server connectivity through Entity Framework Core.

## Tech Stack

- C#
- Entity Framework Core
- SQL Server
- LINQ
- Object-Oriented Programming

## Project Structure

The application includes entities for products, categories, customers, orders, and order details, along with a database context for data access.

## Getting Started

### Prerequisites

- .NET SDK compatible with the project
- SQL Server
- An IDE such as Visual Studio

### Setup

1. Clone the repository.
2. Open the project in Visual Studio.
3. Configure the SQL Server connection string locally.
4. Restore the required NuGet packages.
5. Create or update the database using the migrations available in the project, if applicable.
6. Run the application.

## Learning Objectives

- Apply C# and object-oriented programming concepts.
- Integrate a console application with SQL Server.
- Use Entity Framework Core for database operations.
- Organize application entities and data access logic.
